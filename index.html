Distribution-Aware Local Context Attention (DALCA)

Sep 2026 – Present · work in progress

A research project on cheaper transformer attention: each token reads only the context blocks that matter.

  • Python
  • PyTorch
  • Hugging Face Datasets
  • GPT-2 BPE
  • Designed a 16.3M-parameter decoder-only autoregressive Transformer: 4 layers, 4 heads, 1,024-token context.
  • Designed DALCA with learned attention pooling and causal top-p selection that routes each token to relevant 64-token context blocks.
  • Next: teacher-forcing training with scheduled sampling, then comparison against dense attention on held-out perplexity and generated-text quality.

AI-Powered Cardiopulmonary Disease Detection System

Mar 2026

Reads ECG images and chest X-rays and returns a prediction, a visual explanation and a PDF report.

  • TensorFlow
  • Keras
  • PyTorch
  • ResNet50V2
  • DenseNet-121
  • FastAPI
  • React
  • ECG classifier (3 classes): ResNet50V2 with transfer learning and two-phase fine-tuning, 88.7% test accuracy on about 1,856 images.
  • Fixed class imbalance and overfitting by comparing EfficientNetB0, MobileNetV2 and ResNet50V2.
  • Lung disease detector: DenseNet-121 on 112,120 chest X-rays across 14 classes, 85%+ mean accuracy, with weighted loss.
  • Grad-CAM heatmaps show the regions behind each prediction.
  • Deployed as a FastAPI REST backend connected to a React frontend.
